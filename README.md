# أنياس (Anyas)

أنياس تطبيق عربي يساعد على متابعة الصلاة والأذكار والقرآن والقبلة والمهام اليومية، مع دعم العمل دون اتصال وتطبيق Android مبني من نفس واجهة الويب.

## مكونات المشروع

- **PWA / Web:** واجهة التطبيق في `index.html`، والوظائف في `js/`، والتنسيقات في `css/`.
- **المحتوى:** البيانات المحلية في `data/`، الصور والخطوط في `assets/`، والتسجيلات الصوتية في `audio/`.
- **Android:** غلاف Android داخل `android/` يضمّن نسخة الويب ويضيف الإشعارات والتذكيرات والاختصارات والويدجت.
- **الاختبارات:** فحوصات التكامل الأساسية في `tests/smoke.mjs`.
- **الأتمتة:** GitHub Actions تبني APK وتنفذ فحوصات JavaScript واختبارات التطبيق عند الدفع إلى `main`.

## التشغيل محليًا

يمكن تشغيل نسخة الويب من جذر المشروع عبر أي خادم ملفات ثابت، مثل:

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## الاختبارات

```bash
for file in js/*.js data/*.js; do node --check "$file"; done
node tests/smoke.mjs
```

## بناء تطبيق Android

يتطلب البناء Java 17 وAndroid SDK وGradle:

```bash
gradle --no-daemon -p android assembleDebug
```

قبل البناء، يقوم مشروع Android تلقائيًا بمزامنة ملفات الويب من الجذر إلى أصول التطبيق، ويجهّز فقط ملفات صوت التذكيرات المطلوبة للموارد الأصلية. لا تُعدّل الملفات الناتجة داخل `android/app/src/main/assets` أو `android/app/src/main/res/raw` يدويًا؛ فهي مُستثناة من Git ويعاد توليدها أثناء البناء.
