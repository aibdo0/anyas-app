# أنياس لأندرويد — نسخة Offline-first

يضم APK ملفات HTML/CSS/JavaScript والبيانات والصور والأذان والخطوط محليًا، ويعرضها من `WebViewAssetLoader`. لا يحتاج الاتصال لفتح الواجهة أو استخدام الأقسام المحلية، بما فيها القرآن المخزن، الأذكار، المسبحة، متابعة العبادات والقبلة. يحتفظ Android بجدولة التذكيرات محليًا.

## ما يحتاج اتصالًا اختياريًا

- تُحسب مواقيت الصلاة محليًا فورًا بمكتبة Adhan، مع محاولة تحديث/تخزين المواقيت عبر API المجاني عند توفر الاتصال.
- اسم المدينة والحديث اليومي يُحفظان مؤقتًا بعد تحميلهما، ويُعرض آخر ما خُزّن عند انقطاع الإنترنت. في أول استخدام بلا اتصال قد لا يتوفر حديث اليوم أو اسم المدينة.
- البحث الحي عن أقرب مسجد/فتح الخرائط يحتاج خدمة الخرائط واتصالًا (أو خرائط محفوظة مسبقًا على الجهاز).
- تذكيرات الأذكار تعمل دون إنترنت؛ تذكير الصلاة يستخدم آخر مواقيت محفوظة/محسوبة. تحديث موقع المستخدم أو طريقة الحساب يعيد حسابها.

## البناء والتثبيت

يدفع الفرع `android/apk-wrapper` تغييرات إلى GitHub Actions الذي يبني APK تلقائيًا. افتح **Actions → Android APK → آخر تشغيل → Artifacts → anyas-android-apk** لتنزيل `app-debug.apk`. هذا APK تصحيحي موقّع للتثبيت والاختبار المباشر؛ لا يحتوي مفتاح إصدار متجر Google Play.

بعد التثبيت افتح التطبيق مرة، واسمح للموقع الجغرافي إذا أردت مواقيت مدينتك/القبلة، واسمح بالإشعارات على Android 13+ عند تفعيل التذكير من الإعدادات. تستخدم التنبيهات اليومية `AlarmManager.setAndAllowWhileIdle` غير الدقيق، لذا قد تتأخر حسب وضع توفير البطارية. إعادة تشغيل الهاتف تعيد الجدولة تلقائيًا.

مكتبة Adhan موزعة بموجب MIT، وخطوط Tajawal وAmiri بموجب SIL Open Font License. نصوص الموقع وملفاته تبقى في الفرع؛ لا تُدمج هذه التغييرات في `main` إلا بقرار المستخدم.
