# أنياس لأندرويد

تطبيق WebView خفيف يفتح نسخة الموقع الحالية على GitHub Pages، ويحتفظ بها مستقلة عن هذا الفرع. لا توجد خدمة إشعارات سحابية أو رسوم اشتراك؛ تذكيرات الأذكار الستة ومواقيت الصلاة تُجدول محليًا على جهاز Android عبر AlarmManager.

## البناء

يُبنى ملف APK تلقائيًا عند دفع تغييرات إلى فرع `android/apk-wrapper` عبر GitHub Actions: **Actions → Android APK → آخر تشغيل → Artifacts → anyas-android-apk**. المخرج `app-debug.apk` مناسب للتثبيت والاختبار المباشر. لا يحتوي هذا المستودع على مفتاح توقيع إصدار متجر Google Play.

## الاستخدام

- يتطلب فتح محتوى الموقع اتصالًا بالإنترنت؛ التذكيرات المحفوظة تعمل محليًا عندما يكون التطبيق في الخلفية أو مغلقًا من شاشة التطبيقات الأخيرة.
- من الإعدادات > الإشعارات، فعّل مفاتيح الأذكار أو «الصلاة القادمة». أوقات الورد الستة ثابتة وفق التقسيم المعتمد (04:30، 05:30، 12:00، 15:30، 20:00، 02:00). تنبيه الصلاة قبل الموعد بعشر دقائق ويعتمد على مواقيت الموقع/التعديلات الموجودة في التطبيق.
- على Android 13+ وافق على إذن الإشعارات عند التفعيل. نستخدم التنبيهات غير الدقيقة المسموح بها في Android؛ قد تتأخر قليلًا مع وضع توفير البطارية. لا يتطلب ذلك إذن «المنبهات والتذكيرات» الخاص.
- إعداد «صوت الإشعارات» يختار صوت النظام الافتراضي أو الصمت. إعدادات تقييد البطارية المصنعية أو الإيقاف القسري للتطبيق قد تؤثر على وصول التذكيرات.
- إعادة تشغيل الجهاز تعيد جدولة التذكيرات المحفوظة.
