# بناء وإصدار Android

## البناء التجريبي

يتطلب البناء Java 17 وAndroid SDK وGradle 8.10.2. ينفّذ الأمر التالي فحوصات Gradle ومزامنة المحتوى ثم يبني APK:

```bash
gradle --no-daemon -p android assembleDebug
```

ملف APK الناتج هو `android/app/build/outputs/apk/debug/app-debug.apk`.

## حالة النقل إلى Kotlin

النشاط الذي يفتح عند تشغيل التطبيق هو `NativeMainActivity.kt` بواجهة Jetpack Compose. المرحلة الحالية تضم الرئيسية ومواقيت الصلاة المحسوبة محليًا واختيار المدينة وحساب اتجاه القبلة والأذكار والمسبحة وإعدادات طريقة الحساب والمذهب والتذكيرات. تستورد `NativeReminderSettings.kt` اختيارات الإشعارات المحفوظة في Android، وتحفظها بصيغة متوافقة؛ ويعيد `ReminderScheduler.kt` جدولة التنبيهات دون شبكة. تُقرأ أبواب حصن المسلم من `data/content/azkar-topics.js` بعد تحويلها إلى JSON محلي أثناء البناء.

أصبحت جدولة التنبيهات ومستقبِلات التذكير والإقلاع والمطر وخدمة الصوت وويدجت الصلاة Kotlin. ما زالت `MainActivity.java` واجهة WebView احتياطية للأدوات التي لم تُنقل بالكامل؛ اختبر إعادة الجدولة بعد الإقلاع، وتنبيهات المطر، والويدجت، وترحيل الإعدادات والتقدم المحلي قبل إزالتها.

## البناء الرسمي

الإصدار الرسمي المفضّل للنشر على Google Play هو Android App Bundle:

```bash
gradle --no-daemon -p android bundleRelease
```

يتطلب البناء الرسمي أربعة أسرار في إعدادات المستودع: `ANYAS_KEYSTORE_BASE64` و`ANYAS_RELEASE_STORE_PASSWORD` و`ANYAS_RELEASE_KEY_ALIAS` و`ANYAS_RELEASE_KEY_PASSWORD`. لا ترفع ملف keystore أو كلمات المرور إلى المستودع.

## الأصول والاختبار قبل النشر

ينشئ Gradle ملفات الأصول اللازمة من مصادر المشروع. لا تعدّل محتوى `android/app/src/main/assets` أو `android/app/src/main/res/raw` الناتج يدويًا.

قبل أي إصدار، اختبر مواقيت الصلاة بعد تغيير المدينة وطريقة الحساب والمذهب، وراجع حفظ تقدم الأذكار والمسبحة. اختبر كذلك إذن الإشعارات والتذكيرات بعد إعادة تشغيل الجهاز، والويدجت، والقبلة على أجهزة فعلية، والميزات التي ما زالت تعتمد على الواجهة القديمة. راجع سياسة الخصوصية ومصادر المحتوى قبل نشر إصدار رسمي.
